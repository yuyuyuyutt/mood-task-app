## AI 能力盘点与优化方向

- 新增 `docs/AI-OPTIMIZATION.md`。关键发现：plan-generator 已有完整三阶段 LLM 管线
  （clarificationService → resourceService → planComposer，Ollama 本地优先，规则兜底永不失败）。
- 三个概念现状评级：Prompt Engineering ★★★ / RAG ★★（有搜索无向量）/ Tool Calling ★（完全没有）。
- 优化路线：P0 = JSON Schema 结构化输出（Ollama `format: <schema>`）+ 对话式计划调整（tool calling 首场景）；
  P1 = 本地向量库（embedding + 语义打分第 5 维）+ 内容级 RAG + `/api/chat` system/user 分离。
- 安全原则写入文档：工具白名单（照搬 PATCHABLE_COLUMNS 思路）、写操作用户确认、
  检索内容作为不可信输入隔离标注——把沙箱权限门理念延伸到 AI 层。
- 注意：`llmClient.ts` 只用 `/api/generate` 非流式单 prompt；改 `/api/chat` 可做 system/user 分离与流式。
